Assay 整合后的架构

整合后的 Assay 同时保留上游因子计算平台与本地新增的持久研究工作区。 这些组件都属于 Assay；QFinVerse 是可选的数据生产方，离线研究流程不要求安装 QFinVerse。

完整能力与入口

  1. 数据与计算：本地准备好的美股、A 股、港股数据，以及可选 QFinVerse 日频面板； Python/qlib 双语法 DSL、公共 AST、因子评分、诊断、组合和组合回测。
  2. 共享因子基础设施：FactorDB 的标准化身份、去重、结果存储、相似度查询和批量任务； ADES 可将 FactorDB 计算切片分配给 worker，通过租约和心跳管理任务。
  3. 持续研究：固定数据集配置、目标、尝试预算、成功/失败记录、修订关系、笔记、上下文、 显式重放与带完整性校验的导出/导入。
  4. Agent 接入：36 个 MCP 工具、可替换模型的参考客户端、调用/工具预算、原始回执， 以及 SDK/REST；Agent 决定研究策略，环境执行并记录。
  5. 研究员入口：新版侧栏中的四区工作台、账户与 key、Doc Hub、因子与组合页面。
使用目标 主要入口 结果记录

典型的单 session 流程是注册 dataset、创建 session、读取上下文、执行候选、检查失败、 提交关联修订、添加笔记和导出记录。批量研究走 FactorDB 的 submit/job/query 流程， 可选用 ADES。选择 factordb_ades 研究后端后，session 内的实验会关联持久 FactorDB job 与版本化结果回执。

MCP 共 36 个工具：11 个原有评估/因子库工具、8 个 FactorDB 工具和 17 个研究工具。 HTTP MCP 使用 /mcp/，每个 API 实例有独立的 HTTP 生命周期；本地仍可使用 stdio。

记录和预算的边界

FactorDB 的 factor 是可共享、可去重的表达式及其计算结果；研究 experiment 是一次研究决策， 需要保留失败、假设和父子关系。同一表达式的多次尝试仍分别保存，已有 factor library 也继续保留。 本次整合不合并这些数据库结构，也不删除历史记录。

默认研究后端仍调用进程内评估器。显式选择 factordb_ades 后端，实验会提交给 FactorDB/ADES， 持久保存 job、factor、spec、owner 和逻辑数据版本。超时或重启后调用 assay_experiment_reconcile，沿用原始提交身份，不额外消耗尝试预算。 任务完成与重试耗尽均保存持久回执；跨库写入中断后可恢复，进度和计算用量按 task 幂等计入。

研究工作区约束 session 的尝试次数；FactorDB 每日计算用量归属于后端配置的 owner（默认 research）， 按回执完成时的 UTC 日期记账。这是共享 owner 预算，不是每用户隔离或未来计算资源预留。

研究 session 不同于引擎的临时 panel session。协调操作恢复异步执行证据，不会启动 worker 或恢复模型对话。 同步中断实验仍需检查后显式放弃；仍被跟踪的异步实验使用 assay_experiment_cancel 取消，并保存原因。 取消撤销租约、阻止延迟派发、拒绝迟到结果；不会立即中断远端已运行的原生计算。 若完成回执先被接受，则保留完成结果。取消不退回尝试预算。 使用方法见Agent 研究。

权限与数据

研究 REST 沿用 get_api_key，继承服务 key、个人 key、账户 cookie 和跨来源写入检查。 研究工作区向已授权调用方共享，账户系统不会自动产生每人私有的研究数据库。 网页人工操作仍标记为 human:webui。

保留本地数据存储和上游 QFinVerse 面板读取器。合成数据及本地准备好的行情可以独立使用； 数据集配置哈希仍只标识设置，不冻结实际行情。
